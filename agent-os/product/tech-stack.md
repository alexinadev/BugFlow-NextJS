# Tech Stack

## Frontend

- **Framework:** Next.js 16.1.6 (React 19.2.3)
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Charts & Visualization:** Recharts
- **Drag & Drop:** @dnd-kit (core, sortable, utilities)
- **PDF Generation:** @react-pdf/renderer

## Backend

- **Runtime:** Node.js (via Next.js)
- **API Framework:** Next.js API Routes
- **Authentication:** JWT tokens via jose library
- **Password Hashing:** bcryptjs

## Database

- **System:** PostgreSQL
- **ORM:** Prisma 7.4.0
- **Adapter:** @prisma/adapter-pg

## Development & Build Tools

- **Language:** TypeScript
- **Linting:** ESLint
- **Package Manager:** npm/yarn
- **Containerization:** Docker and Docker Compose
- **Environment:** Next.js Dev Server, Next.js Build & Start

## Key Technologies Summary

- **Type Safety:** TypeScript across frontend and backend
- **Database Layer:** Prisma ORM with PostgreSQL for type-safe queries
- **Authentication:** JWT-based with httpOnly cookies
- **UI Components:** React with client components (use client directive)
- **Container Ready:** Docker support for development and production deployments
