# Application Shell

## Overview

The application shell for BugFlow provides a clean, professional top navigation layout that allows users to easily access all four main sections of the ticketing system. The design emphasizes simplicity and transparency, matching the product's core values.

## Navigation Structure

- **User Ticket Submission** → `/submit` — User Ticket Submission section
- **Admin Dashboard** → `/admin` — Admin Dashboard & Management section
- **Status Tracking** → `/status` — Status Tracking & Notifications section
- **User Portal** → `/portal` — User Portal & Reporting section

## User Menu

- Location: Top right of navigation bar
- Contents: User avatar, name, and logout functionality
- Style: Minimal dropdown with logout option

## Layout Pattern

Top navigation bar with logo on the left, navigation items centered, and user menu on the right. The main content area sits below the navigation bar with appropriate padding.

## Responsive Behavior

- **Desktop:** Full horizontal navigation with all 4 sections visible
- **Tablet:** Navigation items remain visible but with reduced spacing
- **Mobile:** Navigation collapses into a hamburger menu for optimal space usage

## Design Notes

- Uses blue primary color for active navigation items and key accents
- Emerald secondary color for hover states and subtle highlights
- Slate neutral color for backgrounds, borders, and text
- Inter font family for consistent typography
- Light/dark mode support with appropriate color variants
- Focus on accessibility with proper contrast ratios
