# Tailwind Color Configuration

## Color Choices

- **Primary:** `blue` — Used for buttons, links, key accents (e.g., `bg-blue-600`, `text-blue-500`)
- **Secondary:** `emerald` — Used for success states, highlights (e.g., `bg-emerald-500`)
- **Neutral:** `slate` — Used for backgrounds, text, borders (e.g., `bg-slate-50`, `text-slate-600`)

## Usage Examples

### Primary (Blue)
- Primary button: `bg-blue-600 hover:bg-blue-700 text-white`
- Primary text: `text-blue-600`
- Primary border: `border-blue-500`
- Primary background: `bg-blue-50 dark:bg-blue-900/20`

### Secondary (Emerald)
- Success button: `bg-emerald-600 hover:bg-emerald-700 text-white`
- Success text: `text-emerald-600`
- Success border: `border-emerald-500`

### Neutral (Slate)
- Background: `bg-slate-50 dark:bg-slate-900`
- Text: `text-slate-600 dark:text-slate-400`
- Border: `border-slate-200 dark:border-slate-700`

## Dark Mode

All colors have dark mode variants:
- Light: `bg-slate-50`
- Dark: `dark:bg-slate-900`

## Severity Colors

- Blocking/Urgent: `red-600`
- Major/High: `orange-500`
- Minor/Medium: `yellow-500`
- Suggestion/Low: `green-500`
